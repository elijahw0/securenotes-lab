# secure-lab-notes 

I am building out a vulnerable flask api server that is connected to a SQLite database and it allows users to make requests to it. Building out this lab, ill make it purposely vulnerable to various 
OWASP Top 10 vulnerabilities to learn how to exploit them, how they work, remediate them, documenting everything to increase my understanding on application, web and api security.

During this project, I am not allowed to:  

-Visit outside the scope by scanning public IPs or external domains, as this is a venv  

-Test company production or cloud system  

-Use company credentials or use any real information  

-Expose the vulnerable application to the internet  

-Run any exploit script across any system without written permission
